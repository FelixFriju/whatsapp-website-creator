# website3

Reusable multi-page business website template for the existing website platform.

Pages:
- Home
- About
- Products
- Contact

Features:
- Uses platform `WebsiteData`
- Base-path-aware navigation
- Six product cards
- Product images from `data.images.products`
- Product detail modal
- WhatsApp product enquiry
- Dynamic phone, email, location and company details
- Poppins via `next/font/google`
- Template-specific CSS
- No Services page
